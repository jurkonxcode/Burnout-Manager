# Burnout Manager

Aplikasi untuk memantau energi, beban kerja, dan batas diri.

Dibuat karena saya sendiri capek. Cari aplikasi yang cocok, banyak yang terlalu klinis atau terlalu ramai. Jadi bikin sendiri. Pelan-pelan. Dari HP.

## Sekarang bisa apa

- **Log harian** — 20 detik, selesai.
- **Kenalan dulu** — kepribadian, jam biologis, konteks kerja. Biar sarannya tidak generik.
- **Cek burnout** — skrining 10 pertanyaan, skor 0–40.
- **Napas 4-7-8** — kalau butuh tenang cepat.
- **Tren 7 hari** — lihat pola energi dan stres.
- **Hubungi ahli** — muncul kalau skor tinggi.
- **Dark mode**, foto profil, ekspor data.
