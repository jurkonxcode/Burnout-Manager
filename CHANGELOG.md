## [0.2] — 2026-09-27

### Ditambah
- Foto profil. Tap avatar di halaman Profil.
- Halaman Pengaturan lengkap (akun, tampilan, notifikasi, data).
- Dark mode. Tersimpan, tidak perlu setting ulang.
- Onboarding jadi opsional. Setelah isi nama, langsung ke dashboard.
- Kartu "Lengkapi profil" dan "Cek tingkat burnout" muncul di dashboard kalau belum diisi.
- Tombol lewati di TIPI, chrono, dan konteks kerja.
- Tombol "Isi nanti" di asesmen.
- Halaman hasil asesmen dengan skor 0–40 dan saran sesuai level.
- Kartu status di dashboard berubah warna sesuai skor.

### Diubah
- Tampilan dirombak jadi glassmorphism. Kartu kaca, nav mengambang, transisi lebih halus.
- Hero welcome lebih padat: badge, logo compact, judul dengan gradien.
- Auth lebih ringkas.

### Diperbaiki
- Nama user tidak lagi hardcoded "Rani". Sekarang diambil dari onboarding.
- Data log harian: kalau hari ini sudah diisi, ditimpa (tidak dobel).

### Catatan
- Ini masih prototipe. Belum ada backend, belum ada login asli.
- Kalau update dari versi sebelumnya dan tombol tidak jalan, hapus dulu data lokal di browser.
