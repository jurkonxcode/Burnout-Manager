# Kebijakan Privasi

Terakhir diperbarui: 27 September 2026.

## Ringkasnya dulu

Semua data kamu tersimpan di HP kamu sendiri. Tidak dikirim ke server mana pun. Tidak ada yang bisa lihat, termasuk saya.

## Apa yang disimpan

Kalau kamu pakai aplikasi ini, data berikut tersimpan di browser HP kamu:

- **Nama panggilan** — yang kamu isi sendiri. Tidak harus nama asli.
- **Jawaban onboarding** — 10 pertanyaan kepribadian, jam tidur, konteks kerja.
- **Jawaban asesmen** — 10 pertanyaan skrining burnout.
- **Log harian** — energi, stres, beban kerja per hari.
- **Foto profil** — kalau kamu pasang. Di-resize ke max 400×400.
- **Pengaturan** — dark mode atau terang.

Itu saja. Tidak ada tracking, tidak ada analytics, tidak ada cookie.

## Di mana disimpan

Di `localStorage` browser kamu. Anggap saja notes kecil di dalam Chrome atau Safari.

Artinya:
- Data **hanya ada di HP ini**. Tidak bisa dibuka dari HP lain.
- Kalau kamu hapus data browser, data hilang.
- Kalau kamu ganti HP, data tidak ikut pindah.
- Kalau kamu mode Incognito, data hilang saat tab ditutup.

## Siapa yang bisa lihat

Hanya kamu. Tidak ada pihak lain. Tidak ada server. Tidak ada database.

Kalau ada orang lain memegang HP kamu dan membuka aplikasi ini, mereka bisa lihat datanya. Jadi jaga HP kamu seperti biasa.

## Login "Google"

Tombol "Lanjut dengan Google" dan "Lanjut dengan Email" di aplikasi ini **bukan login sungguhan**. Itu simulasi untuk prototipe.

- Tidak ada akun Google yang terhubung.
- Tidak ada data yang dikirim ke Google.
- Tidak ada email kamu yang dikirim ke mana pun.

Kalau nanti saya tambahkan login asli, kebijakan ini akan diperbarui dan kamu akan diberi tahu.

## Data kesehatan

Jawaban asesmen dan log harian termasuk data kesehatan mental. Menurut UU PDP No. 27/2022, data seperti ini butuh perlindungan khusus.

Karena semua tersimpan lokal dan tidak dikirim ke mana pun, risikonya kecil. Tapi tetap:
- Jangan pakai mode Incognito kalau mau data awet.
- Jangan pinjamkan HP tanpa kunci.
- Ekspor data secara berkala kalau penting (Pengaturan → Ekspor).

## Ekspor dan hapus

Kamu bisa:
- **Ekspor** semua data ke file JSON. Kapan saja. Di Pengaturan.
- **Hapus** semua data. Satu tombol di Pengaturan. Tidak bisa dibatalkan.

## Anak-anak

Aplikasi ini tidak dirancang untuk anak di bawah 13 tahun. Kalau kamu di bawah umur, bicara dengan orang tua atau guru dulu.

## Kalau ada masalah

Kalau kamu merasa data kamu tidak aman, atau ada yang aneh, buka Issue di GitHub. Saya baca.

## Perubahan ke depan

Kalau saya ubah cara aplikasi ini menangani data — misalnya menambah backend — saya akan:
1. Bilang di CHANGELOG.
2. Perbarui halaman ini.
3. Minta izin kamu dulu sebelum data apa pun dikirim ke server.

Sampai saat itu, semua tetap lokal.
